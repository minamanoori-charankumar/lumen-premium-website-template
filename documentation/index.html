Lumen

Premium Digital Studio Website Template — Documentation

Install

  1. Extract the ZIP.
  2. Open index.html or upload the folder to your host.
  3. No build step or package installation is required.

Customize

Edit index.html for content, style.css for visual styling, and script.js for interactions.

Assets

Six local SVG demo artworks are included in assets/. Replace them with your own licensed images if desired.

Contact form

The contact form validates in the browser and shows demo submission behavior. Connect it to your own backend or form provider before production.

Fonts

Bricolage Grotesque and Inter are loaded from Google Fonts when online. For offline use, replace them with locally licensed font files.

Demo content

Replace demo testimonials, projects, statistics, contact details, pricing, social links, Privacy, and Terms links before publishing a real site.
