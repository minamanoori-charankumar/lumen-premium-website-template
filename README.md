# Lumen — Premium Digital Studio Website Template

Version 1.0.0

Lumen is a polished, responsive static website template for creative studios,
agencies, freelancers, and modern businesses.

## Tech

- HTML5
- CSS3
- Vanilla JavaScript
- No framework
- No build step
- No npm install required

## Quick start

1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Edit the content in `index.html`.
4. Customize colors, typography, spacing, and responsive styles in `style.css`.
5. Customize interactions in `script.js`.
6. Replace the demo SVG artwork in `assets/` with your own licensed images if desired.
7. Connect the contact form to your own backend/form provider before publishing.

## Included interactions

- Page loader
- Responsive navigation
- Scroll progress
- Hero reveal animation

- Animated counters
- Card tilt interaction
- Button ripple
- Portfolio category filters
- Testimonial slider
- FAQ accordion
- Contact form validation
- Newsletter demo interaction
- Smooth anchor scrolling
- Back-to-top control
- Reduced-motion support

## Images and fonts

This commercial package uses locally generated SVG demo artwork, so it does not redistribute third-party stock photographs.

The page loads Google Fonts (`Bricolage Grotesque` and `Inter`) from Google Fonts when online. If you need a completely self-contained/offline build, replace the font imports with locally licensed font files.

## Browser support

The template is designed for current versions of Chrome, Edge, Firefox, and Safari, with responsive layouts for desktop, tablet, and mobile.
